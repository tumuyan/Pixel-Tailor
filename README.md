# Pixel-Tailor 图片裁缝

一个功能强大的图片裁剪和分割工具，支持自动和手动分割模式。

## 功能特性

### 🎯 核心功能
- **多图片支持**: 可同时处理多个图片文件
- **智能分割**: 支持横向和竖向两种分割方向
- **双模式操作**: 
  - 自动分割模式：智能分析图片内容并生成分割线
  - 手动分割模式：等分或点击添加自定义分割线
- **拖拽调整**: 可通过拖拽调整分割线位置

### 🛠️ 高级功能
- **缩放预览**: 支持图片缩放和适应屏幕显示
- **选择性导出**: 可选择特定部分进行导出
- **多种导出格式**: 支持 PNG、JPEG、WebP 格式
- **两种导出模式**:
  - 合并导出：将选中部分合并为一张图片
  - 分离导出：每个部分导出为独立图片

### 🌐 用户体验
- **双语支持**: 支持中文和英文界面切换
- **响应式设计**: 兼容桌面和移动设备
- **本地计算**: 所有处理都在浏览器本地完成，保护隐私

## 使用方法

### 1. 基本操作
1. 点击"选择图片"按钮，选择一个或多个图片文件
2. 选择分割方向：横向或竖向
3. 选择分割模式：自动或手动

### 2. 自动模式
- 系统会自动分析图片内容并生成分割线
- 可以手动调整分割线位置
- 支持多张图片分别设置分割数量

### 3. 手动模式
- **等分功能**: 输入等分数量，点击"应用"按钮
- **点击添加**: 在图片上点击即可添加分割线
- **拖拽调整**: 拖动分割线调整位置
- **最小间距**: 分割线之间自动保持至少2像素距离

### 4. 导出选项
1. 选择要导出的部分（支持全选、反选等操作）
2. 选择导出模式：合并或分离
3. 选择导出格式：PNG、JPEG、WebP
4. 点击"导出"按钮下载文件

## 技术特点

- **纯前端实现**: 使用 HTML5 Canvas API 进行图片处理
- **无服务器依赖**: 所有计算在浏览器本地完成
- **现代化界面**: 采用渐变色彩和流畅动画效果
- **响应式布局**: 自适应不同屏幕尺寸
